## 一、软件能做什么

电视护眼卫士安装在电视上，帮你**管住看电视的时间**：

| 功能 | 说明 |
| --- | --- |
| 统计观看时长 | 统计你今天看了多久电视（只统计你勾选的"视频应用"） |
| 久看提醒 | 连续看了太久，电视全屏提醒"该休息了"，并倒计时强制休息 |
| 每日上限 | 今天看超过设定时长，弹出 1 小时（3600 秒）护眼页面 |
| 手机管理 | 用手机扫码打开网页后台，在手机上开关监控、改时长、远程喊话提醒 |
| 激活码 | 30 天免费试用；到期后付款获取激活码，在网页上激活即可继续用 |

**一句话流程**：装好 APP → 授权一次 → 手机扫码进后台 → 勾选要管的应用 → 打开"启用监控" → 遥控器长按首页键设为"主屏幕应用"。

## 二、安装前的准备

### 1. 电视要求

- 必须是 **Android TV**（小米、当贝、创维、海尔、康佳等智能电视均可）
- 系统 **Android 6.0 或更高**
- 电视已连上 Wi-Fi 或网线

### 2. 建议安装「当贝桌面」（推荐，非必须）

**强烈建议电视上装有当贝桌面（包名 `com.dangbei.tvlauncher`），但不是硬性要求。**

原理：电视重启后，只有被设为"主屏幕应用（桌面）"的程序才会最先启动。本软件利用这一点在开机时把自己唤醒、启动监控，然后**立刻跳转回你平时用的电视桌面**。

- 因此电视上**需要有一个桌面可跳转**：当贝桌面最省事（默认就是它）；用小米桌面、创维桌面、酷开等**自带桌面同样可以**；
- 如果电视连一个桌面应用都没有（几乎不会出现），建议先装一个桌面或当贝桌面再装本软件。

### 3. 准备安装包

安装包文件名：`tv-eyecare-release-1.0.apk`（约 3.5 MB）。
请通过微信/QQ/U 盘/邮件等任意方式，把这个文件弄到电视上（见第三章）。

## 三、安装 APP（两种方式，任选其一）

> **注意**：本软件**没有上架任何电视应用市场**，请勿在电视自带市场里搜索。请务必使用开发者提供的安装包 `tv-eyecare-release-1.0.apk` 安装。

### 方式一：U 盘 / 手机推送，在电视上点"安装"（推荐给不熟悉电脑的人）

1. 把 `tv-eyecare-release-1.0.apk` 复制到 U 盘，或通过微信"文件传输助手"、QQ、网盘等发送到电视后保存。
2. 把 U 盘插到电视上（或用电视自带的文件管理器找到该文件）。
3. 在电视上打开 **文件管理 / 影音播放器 / 应用安装** 之类的应用，找到这个 APK 文件。
4. 点击它，电视会弹出"是否安装未知应用"之类的提示，选择 **允许 / 安装**。
   - 若提示"禁止安装未知应用"，进入 **设置 → 安全 → 未知来源应用**，允许当前这个应用（或文件管理器）安装，再回来点击安装。
5. 等待安装完成（约 10~30 秒），在电视的"应用列表"里就能看到 **电视护眼卫士** 图标。

> 如果电视提示"无法安装 / 应用未安装"，多半是文件没传输完整（正常约 3.5 MB）。重新拷贝一次，或改用方式二。

### 方式二：用电脑 adb 安装（最稳，适合家人帮忙）

适合有 Windows/Mac 电脑、能插数据线或知道电视 IP 的情况。

**第 1 步：在电脑上打开命令行**

- Windows：按 `Win + R`，输入 `cmd`，回车
- Mac：打开"终端"（在启动台里搜"终端"）

**第 2 步：让电视可以被连接**

方式 A（推荐，无需改系统设置）：先在电视上装好 APP，打开 APP → 用手机扫码进网页后台 → 找到 **ADB 调试** 卡片 → 页面会提示需要执行一次授权命令。**先跳过这步也行**，直接按方式 B。

方式 B（手动开启）：
在电视上进入 **设置 → 关于本机/关于** → 找到 **版本号**，**连续按 7 次**（有的电视叫"连点版本号 7 次"）→ 提示"您已处于开发者模式" → 返回 **设置**，进入 **开发者选项 / 应用管理 → 开发人员选项** → 打开 **USB 调试**（或 **ADB 调试 / 网络调试**）。

> 提示：如果电视允许，本项目还能通过一条 adb 命令自动打开"无线 ADB"（见文末附录），成功后手机/电脑就能用 Wi-Fi 直接连电视，不用插数据线。

**第 3 步：连接并安装**

把下面命令里的 `192.168.2.165` 换成**你家电视的 IP 地址**（在电视上 **设置 → 网络/网络信息** 里能看到，形如 `192.168.x.x`）：

```bash
adb connect 192.168.2.165:5555
adb install -r tv-eyecare-release-1.0.apk
```

看到 `Success` 就是装好了。如果提示 `adb: command not found`，说明电脑没装 adb（Windows 可下载 platform-tools 后把其目录加到 PATH，或直接用方式一）。

> 覆盖升级：以后拿到新版安装包，把上面的 `adb install -r` 再执行一次即可，**不需要卸载旧版**（数据、设置、试用时间都保留）。

**第 4 步（可选，建议做）：开启无线 ADB**

```bash
adb shell pm grant com.tvcontrol.eyecare android.permission.WRITE_SECURE_SETTINGS
```

执行后，重启电视（或重启 APP），无线 ADB 会自动打开，以后电脑不必插数据线也能安装/调试。

> 也可以直接运行[第四章的一次性授权脚本](#1-0-一次性授权脚本推荐最省事)，它会把这条和下面三项权限一起授权，不用一条条敲。

## 四、首次启动：必做的四件事

### 第 1 件事：完成三项授权（**必须，不授权软件没法用**）

第一次打开 APP，屏幕上会出现授权引导页，按 **"授权 1/3 存储权限 → 2/3 使用情况访问 → 3/3 悬浮窗"** 的顺序依次处理。

三项全部授权后引导页自动消失，直接进主界面。**只要有一项没授权，APP 每次打开都会跳回授权页**。

**不想在电视上一步步点？在电脑上跑一次脚本，30 秒全部授完 → 看 [1-0](#1-0-一次性授权脚本推荐最省事)**。下面 1-1 ~ 1-3 是手动做法，脚本授权后可以整段跳过。

#### 1-0 一次性授权脚本（推荐，最省事）

三项权限 **加上** 无线 ADB 自启动权限，**跑一次脚本全部搞定**，不用在电视上一步步点、也不用在电脑上敲 adb 命令。

**两个前置条件**（都要满足）：

1. 「电视护眼卫士」**已经装到电视上**了——脚本只负责授权，**不会帮你安装 APP**（安装见第三章）；
2. 电脑上的 adb **已经能连上电视**（见[第三章方式二的第 2、3 步](#方式二用电脑-adb-安装最稳适合家人帮忙)）。

**脚本从哪来**：向开发者索取安装包时**一并要 `tools` 文件夹**，里面有两个脚本，用你电脑系统对应的那个：

| 你的电脑系统 | 用哪个脚本 |
| --- | --- |
| Windows | `tools\setup-tv-permissions.bat` |
| macOS / Linux | `tools/setup-tv-permissions.sh` |

**怎么运行**：

- **Windows**：把 `setup-tv-permissions.bat` 复制到桌面，**双击运行**即可。
  想指定电视 IP，按 `Win + R` → 输入 `cmd` → 回车，然后粘贴执行：
  ```bat
  tools\setup-tv-permissions.bat 192.168.2.165:5555
  ```
- **macOS / Linux**：打开「终端」，输入：
  ```bash
  bash tools/setup-tv-permissions.sh 192.168.2.165:5555
  ```

> 把命令里的 `192.168.2.165` 换成**你家电视的 IP**（电视上 **设置 → 网络** 里能看到）。
> 如果电视是用**数据线**连电脑的，把参数换成 `adb devices` 里显示的序列号（例如 `ABC123456789`）一样能跑。

**看到什么算成功**：屏幕上会出现 5 行 `[完成]`，最后打印「授权完成」。此时**回到电视上重新打开 APP**，授权引导页会自动跳过，直接进主界面。

**如果脚本报错**：

| 屏幕提示 | 怎么办 |
| --- | --- |
| `[错误] 找不到 adb 命令` | 电脑没装 adb，见[第三章方式二](#方式二用电脑-adb-安装最稳适合家人帮忙) |
| `[错误] 无法连接电视` | ①电视 IP 填错了；②开发者选项/USB 调试没打开；③电视上还没装本软件 |
| 某一行是 `[跳过]` | 该项权限没授上，通常无害；重开 APP 看引导页是否跳过，没跳过就按 [1-1](#11-存储权限) ~ [1-4](#14可选无线-adb-自启动) 手动补 |

> 授权是**一次性的**，以后换版本覆盖升级、平常看电视都不需要再跑脚本。

#### 1-1 存储权限

点 **"授予存储权限"**，在系统弹窗里选 **"允许"**。用于保存监控设置与统计记录。

> 已经跑过 [1-0 一次性授权脚本](#1-0-一次性授权脚本推荐最省事) 的，这一步电视上不会问你，直接跳过。

#### 1-2 使用情况访问（**最重要，不授权观看时长恒为 0**）

点 **"打开设置"**，进入系统的"使用情况访问 / 使用数据"页面：

1. 在列表里找到 **电视护眼卫士**（有的系统叫"护眼卫士"）；
2. 打开开关 / 勾选"允许"；
3. 按返回键回到 APP。

> 找不到开关、或这一页根本打不开时，**最省事的办法是在电脑上跑一次 [1-0 授权脚本](#1-0-一次性授权脚本推荐最省事)**（它会一并授好三项）。
> 想只授这一项，也可以单独执行：
> ```bash
> adb shell appops set com.tvcontrol.eyecare GET_USAGE_STATS allow
> ```
> 或者在电视上手动路径：**设置 → 应用 → 电视护眼卫士 → 权限 → 使用情况访问**。

#### 1-3 悬浮窗权限（**不授权就弹不出护眼提醒**）

点 **"打开设置"**，打开"悬浮窗"开关。

> **⚠️ 小米电视等国产 ROM 上这个按钮可能没反应甚至闪退**：
> 这些系统的设置里**压根没有"悬浮窗"这个页面**（实测 MiTV4 的系统设置未注册该功能）。
> APP 会自动依次尝试：悬浮窗设置页 → 应用详情页 → 厂商权限中心，都打不开时会在电视上弹出提示。
>
> **最省事的办法是在电脑上跑一次 [1-0 授权脚本](#1-0-一次性授权脚本推荐最省事)**（Windows 用 `.bat`、Mac 用 `.sh`），它会把这项一次授好。
> 只授这一项的话，也可以单独执行：
> ```bash
> adb shell appops set com.tvcontrol.eyecare SYSTEM_ALERT_WINDOW allow
> ```
> 或者在电视上手动路径：**设置 → 应用 → 应用管理 → 电视护眼卫士 → 权限 → 悬浮窗**。
> 授权后**重新打开 APP**，引导页会自动跳过。

**没授权会怎样**：APP 每次打开都会跳到授权页面，**护眼提醒弹不出来**（时长统计和使用监控仍然正常）。

#### 1-4（可选）无线 ADB 自启动

引导页最后一步是"无线 ADB 自启动"，**不点不影响任何功能**，只是没法自动开启无线 ADB。需要的话**跑一次 [1-0 授权脚本](#1-0-一次性授权脚本推荐最省事) 就带上了**；也可以在电脑上单独执行：

```bash
adb shell pm grant com.tvcontrol.eyecare android.permission.WRITE_SECURE_SETTINGS
```

### 第 2 件事：记下"设备 ID"

APP 主界面上有一串绿色的字母数字，例如 `9d4959e0da2bd769`，这就是**设备 ID**。

- 付款时备注里会自动带上它；
- 找客服/卖家索取激活码时，**报这串数字**；
- 它是这台电视的唯一身份，**不要泄露给不熟悉的人**。

### 第 3 件事：用手机扫码进入管理后台，并设置密码

1. 电视主界面上有一个**二维码**，下面写着类似 `192.168.2.165:9876` 的地址；
2. 用**手机相机**（或微信"扫一扫"）扫这个二维码；
3. 手机和电视要在**同一个 Wi-Fi** 下；
4. 首次进入会让你**设置管理密码**（留空 = 不设密码，也可以之后再改）：
   - 建议设置 4~6 位数字，避免家里小孩乱改设置。

> 打不开？见 [九、常见问题](#九常见问题faq) 第 1 条。

### 第 4 件事：设为「主屏幕应用」+ 指定启动后跳转的桌面（决定能否开机自启）

这一项**必须在电视上用遥控器完成**，做完之后电视重启才会自动启动护眼卫士。

**第 4-1 步：长按首页键，再按确认键选中它**（这一步是必须的）

1. 拿起遥控器，**按住「首页 / Home」键不放 2~3 秒**；
2. 松手后电视会弹出**最近应用 / 应用切换界面**（有的机型直接弹出应用列表）；
3. 用方向键移动到 **电视护眼卫士**（图标与 APP 一致，可能需要左右翻页）；
4. **按遥控器中间的「确认 / OK」键**选中它；
5. 电视会弹出"是否将电视护眼卫士设为主屏幕应用"，选择 **"始终"**（不要选"仅此一次"或"取消"）；
6. 设置成功后电视会短暂黑屏再回到桌面，属正常现象。

> 提示：部分电视是"长按首页键"直接弹出桌面选择列表，那就直接在列表里选中 **电视护眼卫士** 并选"始终"即可，操作等价。
>
> 找不到"电视护眼卫士"？说明 APP 没装成功，请在 **应用列表** 中确认已安装后重试。

**第 4-2 步：在管理后台选择"启动后跳转桌面"**（建议选当贝桌面）

1. 用手机/电脑打开管理后台（`http://电视IP:9876`）；
2. 找到 **⚙ 监控设置 → 启动后跳转桌面**；
3. 在下拉列表里选择你平时用的桌面：
   - 装了当贝桌面 → 选 **当贝桌面**（显示为 `com.dangbei.tvlauncher` 就是它，**推荐**）；
   - 用电视自带桌面（小米桌面 / 创维桌面 / 酷开等）→ 选对应的那个即可，**同样能用**；
4. 点 **"保存设置"**。

**做完这两步的效果**：电视每次开机 → 先由护眼卫士在后台启动监控 → 立刻跳到你指定的桌面，用户完全感觉不到它存在，但监控已经在工作。

> 如果你更习惯自己手动打开 APP，可以不设主屏幕应用，但**电视重启后监控不会自动启动**，需手动打开一次。

## 六、网页管理后台：手机/电脑都能用

在**手机或电脑浏览器**里打开 `http://电视IP:9876`（例如 `http://192.168.2.165:9876`），输入你设置的密码登录。页面从上到下依次是：

### 1. 实时状态

- **今日观看（分钟）**：今天累计观看的时长，配进度条；
- **每日上限（分钟）**：你设置的上限；
- **当前应用**：电视此刻在用什么应用；
- **监控状态**：显示"监控中"或"监控已暂停"；
- 下方"各应用观看时长"：分应用明细。

### 2. 监控设置 ★最常用

| 开关/输入框 | 作用 | 建议 |
| --- | --- | --- |
| **启用监控** | 总开关。关闭后不统计、不弹提醒 | 想临时看会儿电视就关掉 |
| **弹出提醒** | 控制是否弹全屏护眼提醒页 | 怕突然被"关电视"就关掉 |
| **开机自启** | 电视重启后自动启动护眼卫士（需先按第 4 件事设为"主屏幕应用"） | 建议开启 |
| **启动后跳转桌面** | 指定开机启动后回到哪个桌面 | 一般不用改 |
| **每日上限（分钟）** | 每天最多看多久，超了就弹 3600 秒提醒 | 儿童建议 60~90 |
| **休息间隔（分钟）** | 连续看多久后提醒一次 | 默认 30 |
| **休息时长（秒）** | 每次强制休息多少秒 | 默认 300（5 分钟） |
| **检查间隔（秒）** | APP 每隔多久检查一次（10~600） | 默认 60，调小更及时但更耗电 |

改完点 **"保存设置"**。**关闭"启用监控"后，电视上正在显示的提醒页会在 1 秒内自动消失**。

### 3. 应用管理

1. 顶部三个页签：**已监控 / 视频应用 / 全部应用**，中间可搜索应用名或包名；
2. 切到 **"视频应用"** 页签（APP 已内置视频类应用名单），找到你看视频的 App（如"云视听小电视""咪咕视频""爱奇艺"等）；
3. 点一下即可加入 **"已监控"**；
4. **只有"已监控"里的应用才会被统计时长**。没勾选 = 不统计、不提醒。

> 小技巧：电视上看视频不一定通过视频 App（有时是投屏、浏览器、直播应用）。如果发现时长没涨，回到这里在 **"全部应用"** 里把实际使用的应用也勾上。

### 4. 密码管理

设置或修改网页后台的登录密码。**留空保存 = 清除密码**（以后打开后台不需要输密码，仅建议在自家内网使用）。

### 5. 激活管理

- **设备 ID**：付款、报修都要用；
- **验证服务器**：一般不用改，保持默认即可（换服务器时才填）；
- **接收激活码的邮箱**：填你的邮箱并点 **"保存邮箱"**；保存后会**自动把设备 ID 和邮箱同步给开发者**，便于给你发码；
- **续费（季度卡 ¥10）**：点支付宝链接付款，付款备注已自动带上"设备 ID + 邮箱"，开发者据此发码；
- **输入激活码**：收到邮件后，把形如 `270920-XXXXXXXXXXXX` 的码粘贴进去点 **"激活"**。
  - **联网时通常不用输码**：如果开发者已在后台给你的设备生成并启用了激活码，APP 会在联网时自动激活；
  - 输码是**联网失败时的备用方案**（APP 会在本地校验码的真伪和到期日）。

### 6. 远程提醒

输入提醒语和展示时长（5~300 秒），点 **"发送提醒到电视"**，电视会立刻弹出该提醒。适合用来喊孩子"该写作业了"。

## 七、日常使用：监控是怎么工作的

1. **打开电视 → 打开 APP → 扫码进后台 → 确认"启用监控"是打开的 → 勾选你要管的应用**。完成后可以直接退出 APP，护眼卫士在后台继续运行（电视通知栏有"电视护眼卫士"常驻通知，属正常现象）。

2. **连续观看提醒**：当你勾选的应用连续看到 **"休息间隔"**（默认 30 分钟）时，电视全屏显示"您已连续观看较长时间，请休息 N 秒"，倒计时结束自动恢复。

3. **每日上限提醒**：今天累计观看达到 **"每日上限"**（默认 120 分钟）时，电视弹出 **1 小时（3600 秒）** 的护眼页面。跨天后自动恢复正常，并显示"请明天再来看电视吧"。

4. **临时不想被提醒**：在后台把 **"启用监控"** 关掉即可；电视上的提醒页会**立刻自动关闭**，可以安心看电视。看完后再打开开关即可，统计不会丢。

5. **关掉提醒页的其他办法**（万一电视上没有反应）：
   - 后台把 **"启用监控"** 或 **"弹出提醒"** 关掉；
   - 或在后台点 **"发送提醒到电视"** 之后的任意状态切换；
   - 或用 adb 强制停止再打开：
     ```bash
     adb shell am force-stop com.tvcontrol.eyecare
     adb shell am start -n com.tvcontrol.eyecare/.MainActivity
     ```
   > 提示：护眼页面会屏蔽遥控器的返回/主页键，这是**故意设计**（防止孩子直接跳过休息）。因此关闭它的正规入口是"网页后台开关"。

6. **统计数据不准怎么办**：
   - 确认已在 **应用管理** 里勾选实际使用的应用；
   - 确认系统 **使用情况访问** 权限已开启；
   - 刚打开的应用，系统的使用记录可能**延迟几分钟**才写入，耐心等几分钟再刷新网页。

## 八、激活与续费

### 1. 免费试用

安装后立即享有 **30 天免费试用**（从**第一次安装**的时间算起，即使卸载重装、清除数据，只要电视上的记录还在，时间会接着算）。试用期内所有功能都能用。

### 2. 付费激活（以页面实际显示为准）

1. 电视上打开 APP（试用期结束后电视会直接显示到期页）；
2. 用手机扫码打开电视上显示的**后台二维码**；
3. 在 **激活管理** 里填写 **邮箱** 并点"保存邮箱"；
4. 点 **"支付宝付款"** 链接完成付款（**备注里已自动带上设备 ID 和邮箱**，请勿删除备注）；
5. 开发者收到付款后，在管理后台用你的**设备 ID** 生成激活码并发送到你的邮箱；
6. 收到邮件后，两种激活方式任选：
   - **自动激活（推荐）**：电视联网状态下，等待约 1 分钟或重新打开 APP 即可，页面会变成"已激活"；
   - **手动输入**：把邮件里的激活码粘贴到 **"输入激活码"** 点"激活"。

### 3. 激活码被停用怎么办

如果你在开发者后台把激活码设为"已吊销"（例如退款的订单），电视在**联网状态下重开 APP 后会自动识别并回到未激活状态**，防止继续使用。离线状态下电视仍按本地码的到期日工作。

### 4. 换设备

激活码与设备 ID 绑定。给新电视使用时，把**新电视的设备 ID** 发给开发者，由开发者按新设备 ID 重新生成激活码。

## 九、常见问题（FAQ）

**1. 手机扫码后打不开网页 / 提示无法访问**
- 确认手机和电视连的是**同一个 Wi-Fi**（不是一个连 Wi-Fi 一个用流量）；
- 电视上的地址若显示 `0.0.0.0`，说明电视没取到 IP：请在电视 **设置 → 网络** 里连一下 Wi-Fi，重开 APP；
- 手机浏览器地址栏手动输入 `http://电视IP:9876`；
- 电视上的防火墙/安全软件可能拦截，可临时关闭再试。

**2. 网页提示"需要登录" / 输入密码后提示未授权**
- APP 每次重启（升级安装、崩溃、电视重启）后，网页登录状态会失效，**重新输入一次密码**即可；
- 也可能是电视 IP 变了（路由器重新分配），请用电视上显示的最新地址扫码。

**3. "今日观看"一直是 0**
- 没授权"使用情况访问"→ 电视上打开 APP 会跳到授权页，按第 4 章处理；
- 没在 **应用管理** 里勾选实际使用的应用；
- 系统统计有延迟，切换几次应用或过几分钟再刷新。

**4. 护眼提醒弹不出来 / 一直停在"授权 3/3：悬浮窗"**

这是**国产电视 ROM 的已知问题**：小米电视、当贝等系统设置里**没有注册"悬浮窗"权限页面**，APP 跳转过去必然失败。APP 内部已做多级降级（悬浮窗页 → 应用详情页 → 厂商权限中心），但如果你的电视连应用详情页都没有开关，就得用脚本授权：

**首选：在电脑上跑 [1-0 一次性授权脚本](#1-0-一次性授权脚本推荐最省事)**（Windows 用 `tools\setup-tv-permissions.bat`，Mac 用 `tools/setup-tv-permissions.sh`），它一次授好全部权限。

**只想授这一项**，也可以单独执行：

```bash
adb shell appops set com.tvcontrol.eyecare SYSTEM_ALERT_WINDOW allow
```

或电视上手动：**设置 → 应用 → 应用管理 → 电视护眼卫士 → 权限 → 悬浮窗**。

执行后**重新打开 APP**，引导页会跳过，护眼提醒恢复正常。

> 其他两项权限同理：APP 会依次尝试不同跳转方式，全部失败时会在电视上弹出提示和对应的 adb 命令，照着执行即可。

**5. 提醒页面关不掉 / 一直显示 3600 秒**
- 这是设计如此：护眼页屏蔽遥控器按键，防止跳过休息；
- 正规关闭方式：在手机/电脑后台把 **"启用监控"** 或 **"弹出提醒"** 关掉，电视上该页面会在 1 秒内消失（版本 1.0 起支持）。

**6. 激活码提示"无效 / 已过期 / 已被吊销"**
- 确认码没有多余空格、字母为大写；
- 确认是在**这台电视**上激活（码与设备绑定）；
- 若刚续费，等开发者点"发送"后重新输一次；
- 若确实被吊销，请联系开发者。

**7. 提示"未配置服务器地址" / 激活一直失败**
- 检查电视能否上网；
- 在后台 **激活管理 → 验证服务器** 填入开发者提供的地址并保存；
- 服务器不可达时，APP 会自动尝试备用服务器，仍失败则回退"本地验证"（用之前输入过的码）。

**8. 电视重启后护眼卫士没自己启动**
- 确认后台 **"开机自启"** 已打开；
- 确认已按第 4 件事操作：**长按遥控器首页键 → 按确认键选中"电视护眼卫士" → 选"始终"**（这是开机自启的关键步骤）；
- 确认 **"启动后跳转桌面"** 选的是一个电视上确实存在的桌面（推荐当贝桌面），选错会导致跳不回桌面；
- 部分电视还需要在 **设置 → 应用 → 电视护眼卫士 → 自启动** 里允许自启动（国产 Android 常见）。

**9. 通知栏一直有"正在监控应用使用情况"**
- 正常现象，这是前台服务的常驻通知，**不要手动清除/强行停止**；强行停止后监控会中断，需重新打开 APP。

**10. 电视上找不到"电视护眼卫士"图标**
- 在电视的 **应用列表 / 全部应用** 里按名称查找；
- 长时间找不到，尝试重新安装（先备份好设置截图，重装不会丢试用时间）。

**11. 卸载会怎样**
- 卸载会清掉设置与试用记录。**重装后若电视上没有残留记录，会重新获得 30 天试用**；
- 激活码与设备 ID 绑定，同一台电视的激活码仍可继续使用。

## 十、卸载与重装

**卸载**：电视 **设置 → 应用 → 电视护眼卫士 → 卸载**。

**重装/升级**：把新安装包安装到电视（第三章任一方式）。**升级请直接覆盖安装，不要先卸载**，否则设置和试用记录会丢失。

**恢复出厂/换机**：设备 ID 会变，需要重新授权使用情况访问，并让开发者按新的设备 ID 重新发码。
